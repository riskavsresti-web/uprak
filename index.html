Tutorial Praktik TKJ: Instalasi Sistem Operasi Windows 10

Panduan instalasi bersih (Clean Install) Windows 10 menggunakan Flashdisk Bootable.

Alat dan Bahan

  • 1 Unit PC atau Laptop
  • Flashdisk Bootable Windows 10 (minimal kapasitas 8 GB)

Langkah-Langkah Instalasi

  1. Colokkan flashdisk bootable ke port USB komputer dalam keadaan mati.
  2. Nyalakan komputer lalu tekan tombol masuk BIOS secara berulang (tombol F2, Del, F10, atau Esc sesuai merek motherboard).
  3. Buka tab Boot, atur Boot Priority #1 menjadi flashdisk, lalu tekan F10 -> Yes untuk menyimpan dan restart.
  4. Saat muncul tulisan "Press any key to boot from USB...", tekan tombol apa saja di keyboard.
  5. Pilih bahasa dan format waktu (Indonesian), klik Next -> Install Now.
  6. Klik "I don't have a product key" (jika belum punya lisensi), pilih edisi Windows 10 Pro, lalu klik Next.
  7. Centang "I accept the license terms" -> Next -> pilih Custom: Install Windows only (advanced).
  8. Atur partisi penyimpanan (klik New untuk membuat partisi sistem baru), pilih partisi utama lalu klik Next.
  9. Tunggu proses penyalinan file hingga selesai dan komputer restart otomatis (cabut flashdisk saat restart).
  10. Selesaikan pengaturan awal (wilayah, keyboard, nama user, dan password) hingga masuk ke tampilan Desktop.
